I'm Mash. I build products, run them, and figure it out as I go.

No CS degree. No co-founder (mostly). Just a guy who got tired of waiting for the right conditions and started shipping.

My stack isn't traditional — I use Cursor, Claude, and Antigravity as my main build layer. Not because I can't code, but because leverage matters more than purity. I move fast, I break things, I fix them, and I deploy.

Right now I'm running ventures across edtech, fintech, e-commerce, and B2B SaaS simultaneously. Some are making money. Some are close. All of them are real.
