I don't fit neatly into "developer" or "entrepreneur" — I'm both.

I build and run 5 active products across edtech, fintech, e-commerce, and B2B SaaS. I use AI tools (Cursor, Claude, Antigravity) as my primary build layer — not as a crutch, but as leverage. The goal isn't to write the most code. It's to ship things people actually use.

Everything I build is aimed at the African market — Kenya first, then outward.

## ⚡ agent-preflight

> The pre-deploy quality gate I built for AI-assisted builders — vibe coders, Cursor users, anyone shipping with Claude or Codex.

Most vibe coders ship broken auth, exposed RLS, or uncleaned API keys. This checklist catches all of it before it hits production.

**Covers:** TypeScript/ESLint · Supabase RLS · Paystack & M-Pesa safety · Stream cleanup · Upstash rate limiting · CORS headers · Sentry

**→ [github.com/marsley01/agent-preflight](https://github.com/marsley01/agent-preflight)**

If you build with AI tools, this repo is for you.
